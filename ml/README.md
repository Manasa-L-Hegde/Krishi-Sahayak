# Machine Learning Layer

## Status: Implemented

Phase 1 contains crop classification, engineered climate-mismatch risk scoring, Random Forest/XGBoost/Logistic Regression comparison, SHAP explanations, robustness checks, diagnostics exports, and FastAPI serving.

The serving artifact is generated by `scripts/train_model.py` and stored in `models/`. The seven inference features are N, P, K, temperature, humidity, pH, and rainfall.
