# Generative AI Layer

## Status: Implemented bounded RAG advisory slice

This layer adds English/Kannada retrieval-grounded advisory to the existing FastAPI app. It is not a multi-turn chatbot and does not include Hindi, voice, or chat history.

These URLs are recorded in `sources.json`; `build_index.py` downloads them into `genai/corpus/`, extracts PDF/HTML text, and writes `genai/index/`. Source content is not paraphrased into code.

## Pipeline and safeguard

Documents are split into approximately 350-word chunks with 60-word overlap. `paraphrase-multilingual-mpnet-base-v2` embeds both English and Kannada queries against the English corpus. FAISS inner-product search is used with normalized vectors. A minimum similarity threshold of `0.59` is applied before any LLM call. If no chunk clears it, the service skips Groq entirely and returns: `I don't have verified information on that — please check with your local agriculture officer`.

For qualifying retrievals, Groq receives only the retrieved context and a system/user instruction to answer only from that context, explicitly say when the context is insufficient, and cite source names. A missing or failing Groq credential also fails closed to a fallback response. SHAP is not used for this layer.

## API

`POST /genai/advise` accepts `question` and optional `language` (`English` or `Kannada`) and returns `answer`, cited `sources`, `grounded`, and `fallback` flags. Build the index first with `python -m genai.build_index`.
